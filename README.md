Клон классической игры Flappy Bird с дополнительными функциями, реализованный на Unity.

![Gameplay GIF](Assets/Screenshots/gameplay.gif) <!-- Замените на реальный GIF -->

## 🎮 Особенности
- **Аутентичный геймплей** с физикой как в оригинале
- **Кастомизация** птички (3 скина на выбор)
- **Система очков** с сохранением рекордов
- **Эффекты частиц** при столкновениях
- **Адаптивный UI** под разные разрешения

## 🛠 Технологии
- Unity 2021.3 (2D Physics)
- C# с использованием ООП
- PlayerPrefs для сохранения рекордов
- Unity UI System
- Particle System для визуальных эффектов
