# Flappy - Terminatar | Unity 2D

[![Unity Version](https://img.shields.io/badge/Unity-2022.3.32f1-black?logo=unity)](https://unity.com)


Проект на тему классической игры Flappy Bird , реализованный на Unity.
## Основная механика
 -управлять "птичкой" с целью уворачиваться от выстрелов врагов, уничтожать врагов
## Цель разработки
 -реализовать сложные механики, рациональные технологии
##  Технологии
- Unity 2022.3.32f1 (2D Physics)
- C# ООП MVP
- ObjectPool
- Generics
- Unity UI System
